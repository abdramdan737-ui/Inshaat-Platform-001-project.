# منصة إنشاءات للاستشارات الهندسية

## التشغيل محلياً
1. ثبّت Python 3.10 أو أحدث.
2. افتح الطرفية داخل مجلد المشروع.
3. أنشئ بيئة افتراضية:
   `python -m venv .venv`
4. فعّلها:
   - Windows: `.venv\Scripts\activate`
   - Linux/macOS: `source .venv/bin/activate`
5. ثبّت الحزم: `pip install -r requirements.txt`
6. شغّل التطبيق: `streamlit run main.py`
7. افتح المتصفح على: `http://localhost:8501`

## الدخول إلى المنصة
- الدخول مجاني ومباشر دون إنشاء حساب.
- لا يُطلب بريد إلكتروني أو رقم هاتف أو كلمة مرور.
- لا يوجد تحقق OTP أو تسجيل دخول عبر Google.
- لا توجد اشتراكات أو مدفوعات.

## تنبيه أمني مهم
هذه النسخة لا تحتوي على نظام مصادقة؛ لذلك أي شخص يستطيع الوصول إلى عنوان التطبيق يمكنه استخدامه. لا تنشر التطبيق على الإنترنت بعنوان عام قبل وضعه خلف بوابة وصول مناسبة أو VPN، وضبط جدار ناري وHTTPS وتحديد معدل الطلبات على مستوى الخادم/الوكيل العكسي. إخفاء عناصر الواجهة أو الاعتماد على جلسة Streamlit وحدهما لا يُعدّان حماية أمنية.

## حدود النموذج المالي
القوالب افتراضية وإرشادية. يجب التحقق من بيانات السوق والضرائب والتمويل والافتراضات الفنية لكل مشروع. المخرجات أداة دعم قرار وليست اعتماداً مالياً أو استثمارياً بحد ذاتها.
